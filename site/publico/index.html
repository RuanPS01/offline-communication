Instalar como app (PWA)

Fica na tela inicial e abre mesmo sem internet depois da primeira visita.

  • No Safari, toque em Compartilhar.
  • Escolha Adicionar à Tela de Início.
  • No Chrome, abra o app web e toque em Instalar app (ou no menu, Adicionar à tela inicial).
  • No Chrome ou Edge do computador, use o ícone de instalar na barra de endereço.

Montar uma rede local sem internet

Um aparelho serve, os outros abrem a página dele. Funciona até com quem só tem o navegador.

Virar servidor

  1. Android com o app: em Canais, Rede local, toque em Virar servidor. O app cria o hotspot e mostra o endereço e um QR.
  2. iPhone com o app: ligue o Compartilhamento de Internet nos Ajustes e depois toque em Virar servidor.
  3. Computador: com Node.js, baixe o código-fonte e rode npm install, npm run build e npm run servidor-local. O endereço aparece no terminal.
